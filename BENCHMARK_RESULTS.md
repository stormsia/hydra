## 6. Примененные оптимизации SQLite и движка

1. **Базовые параметры в `.env` и коде по умолчанию:**
   - `CHECKER_CONCURRENCY=5000`
   - `SCHEDULER_BATCH_SIZE=10000`
   - `BATCH_FLUSH_INTERVAL_MS=100`
   - `JUDGE_SELECTION_STRATEGY=lowest_latency`
2. **PRAGMA настройки SQLite:**
   - `PRAGMA journal_mode = WAL` (одновременное чтение и запись без блокировок)
   - `PRAGMA synchronous = NORMAL` (или `OFF` при импорте)
   - `PRAGMA cache_size = -64000` (64 MB кэш страниц)
   - `PRAGMA mmap_size = 268435456` (256 MB memory-mapped I/O)
   - `PRAGMA temp_store = MEMORY` (сортировки и группировки в оперативной памяти)
3. **Индексы:**
   - Добавлен индекс `idx_alive_country_rtt` (`country, rtt_total_ms WHERE state = 1`), сокративший выборку по странам с 18.8 сек до 1.5 мс.
4. **Легковесная телеметрия:**
   - Добавлен endpoint `GET /api/v1/stats/engine` для снятия метрик воркеров в реальном времени за < 1 мс без сканирования базы.
